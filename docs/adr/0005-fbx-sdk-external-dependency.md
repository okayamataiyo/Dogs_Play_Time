# ADR-0005: FBX SDKを許諾確認まで外部依存として扱う

- Status: Accepted
- Implementation: In progress

## 背景
`Dogs_Play_Time.vcxproj`はFBX SDKを`C:\Program Files\Autodesk\...`の絶対パスから参照し、Debug/Releaseで2020.3.7と2020.2など複数のパスが混在している。SDKはリポジトリ外にあり、作業領域内ではヘッダーやライブラリの再配布許諾を確認できる資料が見つかっていない。

## 決定
FBX SDKの再配布許諾が確認できるまでは、ヘッダーやライブラリをリポジトリに同梱しない。開発時は外部依存として扱い、許諾確認後に同梱の可否を改めて判断する。

## 影響
- 開発者にはFBX SDKの個別導入が必要となる。
- 現在混在しているSDKバージョンと絶対パスの統一・設定方法は、別途ビルド再現性の改善として扱う。
- 許諾が確認できるまでは、同梱を前提とする配布・CI設定を行わない。

## 調査メモ（ライセンス本文の読み取り）
ADR-0006の検討で、インストール済みのFBX SDK 2020.3.7に付属するライセンス本文（`License.rtf`、Autodesk LICENSE AND SERVICES AGREEMENT）を読んだ。条文を読み取った結果であり、法的な判断ではない。許諾の確認そのものは、このADRの未決事項として残る。
- 1.1.2・1.1.3: SDKのライブラリをリンクして作ったソフトウェア（このゲームのexe）の複製と配布は認められている。
- 2.1.1(e): Autodeskの資料（ヘッダーやライブラリなど）の全部または一部を第三者に提供することは、書面での許可がなければ認められていない。公開リポジトリへの同梱はこれに当たると読める。この決定（同梱しない）と合う。
- 2.1.1(d): ライセンスを受けた者が所有または借用し、管理しているコンピュータ以外へのインストールは、書面での許可がなければ認められていない。
- 2.1.1(g): インターネットなどの非ローカルなネットワーク越し、仮想化、クラウドなどでのインストールや利用は、ライセンスの種類が特に認めない限り認められていない。
- (d)と(g)から、GitHubのホスト型ランナー（クラウドのVM）にSDKを入れてゲーム本体をビルドするCIは、許諾されていないと読める。そのためADR-0006のCIは、FBX SDKを使わないテストだけを対象にした。ゲーム本体をCIでビルドするには、Autodeskの書面での許可を得るか、自分が管理するコンピュータ（セルフホストランナーなど）を使う必要がある。
