# ADR-0002: 60Hz固定シミュレーションと描画の分離

- Status: Accepted
- Implementation: Not started

## 背景
`Engine/Main.cpp`はINIの`GAME/Fps`設定を使って入力・更新・描画を同じループ内で制御している。移動処理は更新ごとの量で進み、`Engine/Model.cpp`では描画関数内でアニメーションフレームを進めている。描画頻度がゲーム挙動に影響しないことが求められている。

## 決定
ゲームシミュレーションを60Hz固定で更新し、描画処理はシミュレーション更新から分離する。描画FPSを変えても、移動・状態遷移・アニメーションなどのゲーム挙動は変化させない。

## 影響
- `Fps`設定がシミュレーション頻度を変更しないようにする。
- アニメーションの進行を描画呼び出しではなく固定更新側で管理する。
- 更新遅延時の追いつき方や補間方式は実装時に決める。

## 検討した選択肢
- 更新と描画を一体の60Hzループに固定する。
- 経過時間に応じて各移動量を補正する可変時間刻み方式にする。
