# ADR-0007: リソース失敗を必須/任意に分けて安全に扱う

- Status: Accepted
- Implementation: Not started

## 背景
Audio、WIC、Direct3Dなどの初期化・読み込み処理に、ファイル操作やAPI呼び出しの失敗を十分に検査しない経路がある。例えば`Engine/Audio.cpp`はファイル読込結果を検証せずWAVチャンクを検索し、`Engine/Direct3D.cpp`はシェーダーコンパイル結果を確認せず後続処理へ進む箇所がある。

## 決定
必須リソースの初期化・読み込みに失敗した場合は、診断情報を示して安全に起動またはシーン生成を失敗させる。任意リソースの失敗は記録し、安全な代替表示・動作へ切り替える。

## 影響
- 各リソースを必須/任意に分類する。
- 読込APIは失敗を呼び出し元へ伝え、部分初期化時も安全に解放できるようにする。
- 診断の具体的な出力先や代替表現は、実装時にリソースごとに決める。
- `Engine/Texture.cpp`の`Texture::Load`は読み込みのたびに`CoInitialize(NULL)`を呼んでいる。COM初期化は`Audio::Initialize()`が起動時に一度だけ行う（ADR-0004）ため、この呼び出しの要否を整理し、COMの初期化順序に依存しない形にする。
- `Engine/Audio.cpp`の`Audio::Load`は、`data`以外のチャンクを読み飛ばす際に`new char[]`で確保したバッファを解放していない。読込結果の検証と合わせて、確保したバッファが失敗時も含めて解放されるようにする。
- `Audio::Initialize()`は失敗を戻り値（HRESULT）で返すが、`Engine/Main.cpp`は戻り値を見ていない。音声を必須/任意のどちらに分類するかを決め、任意とする場合は、失敗後に`Audio::Load`/`Play`/`Stop`を呼んでも安全に何もしないようにする（ADR-0004は解放順序の整備までを範囲とした）。
