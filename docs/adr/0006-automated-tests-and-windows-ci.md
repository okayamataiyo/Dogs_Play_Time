# ADR-0006: 自動テストとWindows x64ビルドCIを導入する

- Status: Accepted
- Implementation: Not started

## 背景
現在のVisual Studioプロジェクト探索では、専用テストプロジェクトやCI設定を確認できなかった。対象プラットフォームはWindows x64であり、ゲームのロジックとDirect3D等のOS依存処理を分けて検証する必要がある。

## 決定
自動テストを導入し、Windows x64のDebug/ReleaseビルドをCIで確認する。まずはグラフィックス初期化に依存しないロジックをテスト対象とする。

## 影響
- テスト可能なロジックとプラットフォーム依存処理の境界を明確にする。
- CI提供者、テストフレームワーク、具体的なテスト範囲は実装時に選定する。
- 現在のローカル環境ではv143ツールセット不足によりビルド確認できなかったため、CI/開発環境で必要ツールセットを明示する。
